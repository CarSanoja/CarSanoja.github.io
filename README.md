# carsanoja.github.io

Source of [carsanoja.github.io](https://carsanoja.github.io): research-style write-ups of my work on language-model pretraining, agent systems and Kaggle competitions.

Plain HTML and one stylesheet, no build step. The pixel-art banner in `assets/img/` is generated by [room.py](https://github.com/CarSanoja/CarSanoja/blob/main/assets/room.py).
